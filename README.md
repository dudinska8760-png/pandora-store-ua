## Запуск

Збірка не потрібна: відкрийте `index.html` у браузері
або запустіть локальний сервер: `python -m http.server 8000`.

## ЛР3: застосовані CSS-технології

| Технологія | Де і для чого |
| --- | --- |
| Зовнішні CSS-файли + `@import` | `style.css` підключає `base.css` → `layout.css` → `components.css` → `responsive.css`; у HTML підключено лише `style.css` |
| CSS-змінні (`:root`) | кольори брендбуку (рожевий акцент, чорний, сірі), шрифт Comfortaa, ширина контейнера; текстові кольори з контрастом ≥ 4.5:1 |
| CSS Grid | шапка (3 колонки × 2 рядки з `grid-template-areas`), сітка бестселерів 3×2 з однаковими квадратними картками (`aspect-ratio`), сітка каталогу, картка товару, футер, форми входу (`auto-fit` + `minmax`) |
| Flexbox | списки меню, фільтри каталогу, фото категорій, форма підписки, пагінація, мітки в картках |
| Медіазапити | точки 1024 / 900 / 768 / 480 px та ≥ 1440 px; одна й та сама розмітка для телефону, планшета й ПК |
| Адаптивне меню | на ≤ 768 px — бургер-кнопка (`aria-expanded`, `aria-controls`, закриття по Esc); без JavaScript меню залишається видимим |
| `clamp()`, `min()` | плавні розміри заголовків і зображень без зайвих медіазапитів |
| Стилізація форм | єдиний вигляд полів, `:focus`, `:hover`, кастомний `select`, `fieldset`/`legend`, `accent-color` для чекбоксів і радіокнопок |
| Клієнтська валідація | HTML5-атрибути (`required`, `type=email`, `minlength`, `pattern`) + `js/main.js` показує повідомлення українською під полем, `aria-invalid`, `aria-describedby`; стилі `.touched:invalid`, `:user-invalid` |
| Таблиці | кошик: шапка в кольорі бренду, «зебра», `:hover`, горизонтальне прокручування на вузьких екранах |
| Препроцесори | не застосовувалися (чистий CSS + змінні) |

### Кросбраузерність

- Для Safari/iOS: `-webkit-text-size-adjust`, `-webkit-appearance`, `summary::-webkit-details-marker`, `-webkit-overflow-scrolling`.
- Селектори `:user-invalid` і `:has()` винесені в окремі правила — старі браузери їх просто ігнорують, решта стилів працює.
- Перевірено в Chromium (Chrome / Edge) через емуляцію екранів 320, 375, 768, 1024, 1440 px: горизонтального прокручування та помилок у консолі немає.

## Особливості реалізації

- Семантична розмітка: `header`, `nav`, `main`, `footer`, `section`, `article`.
- Верстка відтворює макет із ЛР1 (двоповерхова шапка, нумеровані категорії, сітка каталогу, акордеони в картці товару, 4-колонковий футер).
- Фото вирізані з макета ЛР1 й збережені у WebP (разом ≈ 0,4 МБ); усі мають `alt`, `width`/`height`, нижні — `loading="lazy"`.
- Доступність: посилання «Перейти до вмісту», `aria-current`, підписи `label` до всіх полів,
  контраст тексту ≥ 4.5:1 (WCAG 2.1 AA), видимий фокус.
- Адаптивна верстка 320–1920 px (CSS Grid / Flexbox, медіазапити, бургер-меню).
- Код перевірено в [W3C Markup Validator](https://validator.w3.org/) — без помилок.
