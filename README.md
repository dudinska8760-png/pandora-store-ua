## Структура проєкту

```text
pandora-store-ua/
├── images/            # WebP-фото з макета (ЛР1), оптимізовані, + SVG-логотипи
│   ├── logo.svg, logo-white.svg
│   ├── hero.webp, promo.webp, visit.webp ...
│   └── p-*.webp       # товари каталогу
├── css/
│   └── style.css      # стилі за брендбуком (Comfortaa, рожевий акцент)
├── js/
│   └── main.js        # рік у футері, демо-обробка форм, кнопка «Додати в кошик»
├── index.html         # Головна
├── catalog.html       # Каталог (форма фільтрів)
├── product.html       # Картка товару
├── cart.html          # Кошик та оформлення замовлення (форма)
├── delivery.html      # Доставка та оплата
├── about.html         # Про Pandora
├── contacts.html      # Контакти (форма звернення)
├── login.html         # Вхід та реєстрація (дві форми)
├── .gitignore
└── README.md
```

## Запуск

Збірка не потрібна: відкрийте `index.html` у браузері
або запустіть локальний сервер: `python -m http.server 8000`.

## Особливості реалізації

- Семантична розмітка: `header`, `nav`, `main`, `footer`, `section`, `article`.
- Верстка відтворює макет із ЛР1 (двоповерхова шапка, нумеровані категорії, сітка каталогу, акордеони в картці товару, 4-колонковий футер).
- Фото вирізані з макета ЛР1 й збережені у WebP (разом ≈ 0,5 МБ); усі мають `alt`, `width`/`height`, нижні — `loading="lazy"`.
- Доступність: посилання «Перейти до вмісту», `aria-current`, підписи `label` до всіх полів,
  контраст тексту ≥ 4.5:1 (WCAG 2.1 AA), видимий фокус.
- Адаптивна верстка 360–1920 px (CSS Grid / Flexbox).
- Код перевірено в [W3C Markup Validator](https://validator.w3.org/) — без помилок.
