## Структура проєкту

```text
pandora-store-ua/
├── images/               # зображення у форматі WebP та SVG-логотипи
├── css/
│   ├── style.css         # головний файл: підключає модулі через @import
│   ├── base.css          # змінні, скидання стилів, типографіка, посилання, списки, таблиці
│   ├── layout.css        # шапка, сітки Grid/Flexbox, макети сторінок, футер
│   ├── components.css    # меню, кнопки, картки, форми та їх валідація, акордеон
│   └── responsive.css    # медіазапити для планшетів і телефонів
├── js/
│   └── main.js           # бургер-меню, валідація форм, рік у футері, «Додати в кошик»
├── index.html            # Головна
├── catalog.html          # Каталог
├── product.html          # Картка товару
├── cart.html             # Кошик та оформлення замовлення
├── delivery.html         # Доставка та оплата
├── about.html            # Про Pandora
├── contacts.html         # Контакти
├── login.html            # Вхід та реєстрація
├── .gitignore
└── README.md
```

## Запуск

Збірка не потрібна: відкрийте `index.html` у браузері
або запустіть локальний сервер: `python -m http.server 8000`.

## Застосовані CSS-технології

| Технологія | Де і для чого |
| --- | --- |
| Зовнішні CSS-файли та `@import` | `style.css` підключає `base.css`, `layout.css`, `components.css`, `responsive.css`; у HTML підключено лише `style.css` |
| CSS-змінні (`:root`) | кольори брендбуку (рожевий акцент, чорний, сірі), шрифт Comfortaa, ширина контейнера |
| CSS Grid | шапка (`grid-template-areas`), сітка бестселерів 3×2 з однаковими квадратними картками, каталог, картка товару, футер, форми входу (`auto-fit` + `minmax`) |
| Flexbox | меню, фільтри каталогу, форма підписки, пагінація, мітки в картках |
| Медіазапити | точки 1024, 900, 768 та 480 px і від 1440 px; одна розмітка для телефона, планшета й комп’ютера |
| Адаптивне меню | до 768 px — бургер-кнопка (`aria-expanded`, `aria-controls`, закриття клавішею Esc); без JavaScript меню залишається видимим |
| `clamp()`, `min()` | плавні розміри заголовків і зображень без зайвих медіазапитів |
| Стилізація форм | єдиний вигляд полів, стани `:hover` і `:focus`, власна стрілка в `select`, `fieldset`/`legend` |
| Клієнтська валідація | HTML5-атрибути (`required`, `type`, `minlength`, `pattern`) і повідомлення українською під полями (`aria-invalid`, `aria-describedby`) |
| Таблиці | кошик: фірмова шапка, чергування рядків, підсвічування при наведенні, горизонтальне прокручування на вузьких екранах |
| Препроцесори | не застосовувалися (чистий CSS зі змінними) |

## Кросбраузерність

Сайт перевірено на розмірах екрана 320, 375, 768, 1024 і 1440 px: горизонтального
прокручування та помилок у консолі немає.

| Браузер | Статус |
| --- | --- |
| Chrome | ✅ |
| Edge | ✅ |

Селектори `:user-invalid` і `:has()` винесені в окремі правила, тому старі браузери
їх просто ігнорують, а решта стилів працює.

## Особливості реалізації

- Семантична розмітка: `header`, `nav`, `main`, `footer`, `section`, `article`.
- Верстка відтворює макет магазину: двоповерхова шапка, нумеровані категорії, сітка каталогу, акордеони в картці товару, чотириколонковий футер.
- Зображення збережені у форматі WebP (разом ≈ 0,4 МБ); усі мають `alt`, `width` і `height`, а ті, що нижче першого екрана, — `loading="lazy"`.
- Доступність: посилання «Перейти до вмісту», `aria-current`, підписи `label` до всіх полів, контраст тексту не нижче 4.5:1 (WCAG 2.1 AA), помітний фокус.
- Адаптивна верстка від 320 до 1920 px.
- HTML-код перевірено у [W3C Markup Validator](https://validator.w3.org/) — без помилок.
